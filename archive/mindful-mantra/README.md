# Mindful Mantra images

The images that accompanied four of the nineteen posts on
`mindfulmantra.blogspot.com`, kept here because the blog is being taken down and
these are the only remaining copies. Saved at original resolution, straight from
Blogger.

**Nothing here is served.** The build only publishes `public/`, so these files
have no URL on the site. That is deliberate: three of the four are not Khalid's
work, and putting them under `public/` would republish them on his domain even
with no page linking to them.

To use one, copy it into `public/` and reference it from the piece's markdown.
Only `thoughts-wander.jpg` is his to use freely.
